הבהרה לגבי הרשאות אדמין

צריך Administrator בתוך ה-Win10 VM — לא על המחשב הפיזי. המשתמש ב-Win10 Eval הוא Administrator כברירת מחדל. לחיצה ימנית על כלי Sysinternals → "Run as administrator" כשנדרש.

# S-1-16-12288 = High Mandatory Level = admin token

בנה את סימולטור ה-C2 בעצמך (ללא קובץ מהמדריך)

# בתוך Win10 VM (PowerShell כאדמין):
# 1. התקן Python
winget install -e --id Python.Python.3.12 -h
# 2. התקן pyinstaller
python -m pip install --user pyinstaller

# 3. שמור את קוד המקור של הסימולטור
mkdir C:\Tools 2>$null
@'
import ctypes, socket, time, winreg, sys
# Persistence: HKCU Run key
k = winreg.OpenKey(winreg.HKEY_CURRENT_USER,
    r"Software\Microsoft\Windows\CurrentVersion\Run", 0, winreg.KEY_SET_VALUE)
winreg.SetValueEx(k, "Lab2Sim", 0, winreg.REG_SZ, sys.executable + " " + __file__)
winreg.CloseKey(k)
# הקצאת RWX (יעד Live malfind)
VirtualAlloc = ctypes.windll.kernel32.VirtualAlloc
buf = VirtualAlloc(0, 4096, 0x3000, 0x40)   # PAGE_EXECUTE_READWRITE
ctypes.memset(buf, 0x90, 4096)               # מילוי ב-NOPs
# "C2" loopback
try:
    s = socket.socket(); s.connect(("127.0.0.1", 4444))
except: pass
print("simulator alive, RWX @", hex(buf))
while True: time.sleep(60)
'@ | Out-File -Encoding ASCII C:\Tools\benign-c2-sim.py

# 4. הידור ל-exe
cd C:\Tools
python -m PyInstaller --onefile benign-c2-sim.py
copy dist\benign-c2-sim.exe C:\Tools\

# 5. אופציונלי — listener על 127.0.0.1:4444 כדי שה-connect יצליח
Start-Job { python -c "import socket; s=socket.socket(); s.bind(('127.0.0.1',4444)); s.listen(); s.accept()" }
C:\Tools\benign-c2-sim.exe קיים. הרץ אותו → Process Explorer מציג ; reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v Lab2Sim מחזיר את הנתיב.

  • תהליך benign-c2-sim זוהה כחשוד תוך פחות מ-10 דקות
  • IOCs מתועדים: Hash, Path, Run Key, Mutex, IP:Port
  • אישור על RWX private region (live malfind)
  • Verdict ציון מצטבר ≥ 4 = Malware
  • התהליך נשמר ב-procdump לניתוח offline

שאלות לסיכום

  1. מהי ההזדמנות שמספק Process Explorer ש-Task Manager לא?
  2. מדוע RWX private memory = "live malfind"?
  3. איך אפשר לזהות DLL Hijacking דרך Listdlls?
  4. מה היתרון של Procdump עם trigger -e (on exception) על פני dump ידני?
  5. בעבודת SOC אמיתית — באיזה סדר היית מפעיל את כלי Sysinternals? נמק.
  6. ניתן לסמוך על Sysinternals מול rootkit ברמת Kernel? למה?
  7. איך sigcheck משלב את התהליכים של מעבדה 1 לשורה אחת?

סיכום

Sysinternals Live Triage = הכלי הראשון של SOC Tier-1 ב-Windows. ב-10 דקות אפשר לזהות נוזקה חיה, לתעד IOCs, ולהקפיא ראיות. אם מצאת 4+ סימנים = Malware בוודאות גבוהה. הכלים: Process Explorer, Autoruns, TCPView, VMMap, Sigcheck, Procdump, Listdlls.
