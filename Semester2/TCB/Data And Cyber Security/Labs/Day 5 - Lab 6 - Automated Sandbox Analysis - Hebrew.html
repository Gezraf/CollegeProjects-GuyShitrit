מעבדה 6: ניתוח אוטומטי בארגז חול (Sandbox)

יום 5 — ניתוח נוזקות ויסודות SIEM
יום 5 משך: כ-45 דקות רמה: בינונית סביבה: מכונה וירטואלית Windows + דפדפן

מטרות

  • שימוש בשלושה ארגזי חול ציבוריים אוטומטיים: VirusTotal, Any.run, Hybrid Analysis
  • הגשת קובץ חשוד בשתי דרכים: לפי גיבוב SHA-256 ובאמצעות העלאת קובץ
  • קריאת דוח ארגז חול — יחס זיהוי, התנהגות, רשת, קבצים שנוצרו
  • חילוץ סימני התפשרות (IOCs) מתוך דוח
  • מיפוי התנהגות נוזקה לטכניקות MITRE ATT&CK
  • השוואה בין שלושת ארגזי החול מבחינת מהירות, אינטראקטיביות, רמת פירוט ועלות
  • לדעת מתי אסור להעלות קובץ לארגז חול ציבורי

לפני שמתחילים

מעבדה זו מוכנה מראש במלואה. לפני שאתם מתחילים, יש לכם:

  • מכונה וירטואלית Windows 10, פועלת, שולחן עבודה נטען, עם תמונת מצב (snapshot) נקייה שנשמרה.
  • דפדפן אינטרנט מודרני בתוך המכונה הווירטואלית (Microsoft Edge או Chrome) — כבר מותקן.
  • גישה תקינה לאינטרנט בתוך המכונה הווירטואלית (ארגזי החול הם שירותים מקוונים).
  • התיקייה הריקה C:\lab6 כבר נוצרה במכונה הווירטואלית (המדריך הכין אותה).
  • מחרוזת הבדיקה EICAR — זהו קובץ הבדיקה הסטנדרטי והבלתי מזיק לאנטי-וירוס. הוא אינו נוזקה. כל מנוע AV מסמן אותו בכוונה כדי שתוכלו לבדוק זיהוי בבטחה. המחרוזת המדויקת ניתנת בשלב 2.
אף דגימת נוזקה אינה מורדת לדיסק במעבדה זו. שלבים 1, 3 ו-4 משתמשים בחיפוש מבוסס גיבוב (שום דבר לא נוחת על הדיסק = אין בעיית אנטי-וירוס). רק שלב 2 כותב קובץ — וקובץ זה הוא מחרוזת הבדיקה הבלתי מזיקה EICAR, שמטופלת בשלב 0.
בצעו את הכול בתוך המכונה הווירטואלית, לעולם לא במחשב האמיתי שלכם. בתוך המכונה הווירטואלית אתם המנהל (Administrator) — אין צורך בהרשאת מנהל של מארח (host).

שלב 0 — טיפול באנטי-וירוס (בצעו זאת ראשון)

בשלב 2 תיצרו את קובץ הבדיקה EICAR על הדיסק. Microsoft Defender מסמן את EICAR בכוונה ויעביר אותו להסגר (ימחק אותו) ברגע שייכתב. כדי למנוע זאת, הוסיפו חריגה (exclusion) של Defender לתיקיית המעבדה לפני שנוצר קובץ כלשהו.

  1. 0.1 פתחו PowerShell כמנהל
    Right-click the Start button -> "Windows PowerShell (Admin)" -> Yes
    נפתח חלון PowerShell כחול. השורה מתחילה ב-PS C:\WINDOWS\system32>.
  2. 0.2 הוסיפו חריגת Defender לתיקיית המעבדה
    Add-MpPreference -ExclusionPath "C:\lab6"
    הפקודה חוזרת לשורת הפקודה ללא פלט. אין שגיאה = זה עבד.
  3. 0.3 ודאו שהחריגה רשומה
    Get-MpPreference | Select-Object -ExpandProperty ExclusionPath
    PowerShell מדפיס את C:\lab6 ברשימת הפלט.
  4. 0.4 (רק כפתרון חלופי) השביתו הגנה בזמן אמת

    אם למכונה הווירטואלית שלכם יש מדיניות שמתעלמת מהחריגה, השביתו במקום זאת את הניטור בזמן אמת למשך המעבדה:

    Set-MpPreference -DisableRealtimeMonitoring $true
    אין פלט = זה עבד. Defender כבר אינו סורק קבצים בעת כתיבה.
    בצעו זאת רק בתוך המכונה הווירטואלית המבודדת של המעבדה. בסוף המעבדה, הפעילו זאת מחדש באמצעות Set-MpPreference -DisableRealtimeMonitoring $false או פשוט שחזרו את תמונת המצב הנקייה.
אם זה לא עבד — "Add-MpPreference is not recognized": לא פתחתם PowerShell כמנהל. סגרו אותו ובצעו מחדש את שלב 0.1. אם אתם מקבלים שגיאת "Access denied", Defender מנוהל על ידי מדיניות קבוצתית (group policy); השתמשו בפתרון החלופי בשלב 0.4.

שלב 1 — VirusTotal: חיפוש לפי גיבוב (ללא קובץ על הדיסק)

הדרך הבטוחה ביותר לבדוק קובץ היא לפי הגיבוב שלו. אתם לעולם לא מעלים את הקובץ — אתם שואלים את VirusTotal "האם ראית את הגיבוב הזה בעבר?". נשתמש בגיבוב SHA-256 הציבורי והידוע של קובץ הבדיקה EICAR.

  1. 1.1 פתחו את VirusTotal
    In the browser, go to:  https://www.virustotal.com
    דף הבית של VirusTotal נטען עם תיבת חיפוש גדולה ושלוש לשוניות: FILE, URL, SEARCH.
  2. 1.2 חפשו את גיבוב ה-SHA-256 הידוע

    לחצו על הלשונית SEARCH, הדביקו את הגיבוב הזה בתיבה והקישו Enter:

    275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f
    דף דוח נפתח מיד (אין צורך בהעלאה). הקובץ הוא קובץ הבדיקה EICAR, 68 בתים.
  3. 1.3 קראו את יחס הזיהוי

    בראש הדוח, הסתכלו על העיגול הגדול ועל הלשונית Detection.

    Detection ratio:  about  60+ / 70   security vendors flagged this file
Typical label:    EICAR-Test-File  /  Eicar-Test-Signature  /  not-a-virus
Threat category:  test file
    אתם רואים מספר זיהויים גבוה, אך כל התוויות אומרות "EICAR" או "Test-File" — מה שמאשר שזהו קובץ בדיקה מכוון, לא נוזקה אמיתית.
  4. 1.4 קראו את סיכום ההתנהגות

    לחצו על הלשונית BEHAVIOR. VirusTotal מפעיל דגימות בארגזי החול שלו ומסכם מה הן עשו.

    For the EICAR test file the BEHAVIOR tab is mostly empty -
it is just a 68-byte text string and performs no actions.
For real malware this tab shows:  processes created, files written,
registry keys set, network connections, MITRE ATT&CK techniques.
    אתם מבינים היכן נמצאים נתוני ההתנהגות. שימו לב גם ללשונית DETAILS (גיבובים, סוג קובץ) וללשונית RELATIONS (דומיינים/כתובות IP שאליהם הקובץ פנה).
אם זה לא עבד — "No matches found": בדקו שהדבקתם את הגיבוב המלא בן 64 התווים ללא רווחים. חיפוש גיבוב עובד רק אם מישהו כבר הגיש את הקובץ הזה. אם הקובץ חדש לגמרי, עליכם להעלות אותו (שלב 2).

שלב 2 — VirusTotal: העלאת קובץ

כעת תיצרו את קובץ הבדיקה הבלתי מזיק EICAR ותעלו אותו. שלב 0 חייב להיות מבוצע כבר כדי ש-Defender לא ימחק אותו.

  1. 2.1 צרו את קובץ הבדיקה EICAR

    בחלון ה-PowerShell של המנהל משלב 0, הריצו את הפקודה המדויקת הזו. המחרוזת חייבת להיות מדויקת — תו שגוי אחד והיא כבר אינה קובץ הבדיקה.

    Set-Content -Path "C:\lab6\eicar.txt" -Value 'X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*' -NoNewline -Encoding ascii
    הפקודה חוזרת ללא פלט. הקובץ C:\lab6\eicar.txt קיים כעת.
  2. 2.2 ודאו שהקובץ שרד
    Get-Item "C:\lab6\eicar.txt" | Select-Object Name, Length
    PowerShell מדפיס eicar.txt עם Length 68. הקובץ נמצא על הדיסק ו-Defender לא מחק אותו.
  3. 2.3 העלו אותו ל-VirusTotal
    On VirusTotal, click the FILE tab -> "Choose file"
Browse to  C:\lab6\eicar.txt  -> Open
Wait for the scan to finish (a few seconds)
    מופיע דף דוח. יחס הזיהוי גבוה (60+ / 70) והתוויות אומרות EICAR-Test-File — אותו פסק דין שראיתם לפי גיבוב בשלב 1.
  4. 2.4 השוו בין חיפוש גיבוב להעלאת קובץ

    שימו לב שהדוח מההעלאה הוא אותו דוח שראיתם בשלב 1. הסיבה לכך היא שה-SHA-256 של הקובץ שלכם זהה לגיבוב שחיפשתם.

    Hash lookup  -> nothing leaves your machine, instant, but only works
                if the file was seen before.
File upload  -> works for any file, BUT the file is now PUBLIC on
                VirusTotal and downloadable by paid subscribers.
    אתם יכולים לנסח את המאזן (trade-off): העדיפו חיפוש גיבוב; העלו רק כאשר הקובץ אינו מוכר וגם אינו רגיש.
כל מה שאתם מעלים ל-VirusTotal הופך לזמין למנויים המשלמים שלו (ספקי AV, חוקרים — וגם תוקפים). לעולם אל תעלו קובץ ייחודי, ארגוני או רגיש. ראו את אזהרת "דליפת נתונים" בסוף מעבדה זו.
אם זה לא עבד — הקובץ נעלם לפני שהספקתם להעלות אותו: Defender העביר אותו להסגר מכיוון ששלב 0 דולג או שנתיב החריגה שגוי. בצעו מחדש את שלב 0, ודאו ש-Get-MpPreference מציג את C:\lab6, ואז צרו מחדש את הקובץ בשלב 2.1.

שלב 3 — Any.run: ארגז חול אינטראקטיבי

Any.run הוא ארגז חול מקוון אינטראקטיבי: נוזקה רצה במכונה וירטואלית Windows אמיתית ואתם צופים בה בזמן אמת — עץ תהליכים, רשת, צילומי מסך — ואף יכולים ללחוץ בתוך המכונה הווירטואלית. נחפש את דגימת EICAR לפי גיבוב (ללא העלאה).

  1. 3.1 צרו חשבון Any.run חינמי
    In the browser, go to:  https://any.run
Click "Sign up" -> register with an email -> confirm the email
Log in
    אתם מחוברים ורואים את לוח המחוונים של Any.run עם פיד "Public Submissions" ותיבת חיפוש.
  2. 3.2 חפשו את גיבוב EICAR בהגשות הציבוריות

    השתמשו בתיבת החיפוש שבחלק העליון. הדביקו את אותו SHA-256 משלב 1:

    275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f
    מופיעה משימת ניתוח ציבורית אחת או יותר של קובץ הבדיקה EICAR. לחצו על העדכנית ביותר כדי לפתוח את הדוח שלה.
  3. 3.3 צפו בעץ התהליכים החי

    בדף הדוח, מצאו את לוח Process tree (בצד) ואת הקלטת המסך של המכונה הווירטואלית.

    Process tree:  shows the parent/child chain of every process started.
               For EICAR the tree is tiny (it does nothing).
               For real malware you would see, e.g.:
               winword.exe -> cmd.exe -> powershell.exe -> rundll32.exe
Verdict tag:   top of the report - "No threats detected" for EICAR.
    אתם יודעים לקרוא עץ תהליכים ולמצוא את תווית פסק הדין הכוללת בדוח של Any.run.
  4. 3.4 בחנו את פעילות הרשת

    פתחו את הלשונית Network / Connections בדוח.

    This tab lists:  HTTP/HTTPS requests, DNS queries, contacted IPs,
                 and any Suricata IDS alerts that fired.
For EICAR this is empty. For real malware this is the main IOC source -
C2 domains and IPs are documented here.
    אתם יודעים היכן Any.run מתעד IOCs של רשת. האינטראקטיביות היא היתרון המרכזי של Any.run: תוכלו ללחוץ דרך מתקין מזויף כדי להפעיל התנהגות נסתרת.
אם זה לא עבד — החיפוש לא מחזיר דבר: נסו לחפש את המילה eicar במקום את הגיבוב, או דפדפו בפיד Public Submissions. השכבה החינמית מציגה רק משימות ציבוריות; אינכם צריכים להגיש קובץ משלכם עבור מעבדה זו.

שלב 4 — Hybrid Analysis: דוח מפורט

Hybrid Analysis (מופעל על ידי CrowdStrike Falcon Sandbox) מפיק את הדוח הכתוב המפורט ביותר מבין השלושה — מיפוי מפורש של MITRE ATT&CK, רשימת IOC מלאה, וקבצים שנוצרו. נקרא דוח EICAR קיים לפי גיבוב.

  1. 4.1 פתחו את Hybrid Analysis וחפשו את הגיבוב
    In the browser, go to:  https://www.hybrid-analysis.com
Paste this SHA-256 into the search box and press Enter:
275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f
    מופיעה תוצאה עבור קובץ הבדיקה EICAR. לחצו עליה כדי לפתוח את הדוח המלא.
  2. 4.2 קראו את פסק הדין והניקוד של האיום

    בראש הדוח, קראו את באנר פסק הדין ואת Threat Score.

    Verdict:       "No specific threat" / "Whitelisted" for EICAR
Threat Score:  low (EICAR does nothing harmful)
AV Detection:  high % - because every engine flags EICAR by signature
    אתם יכולים לאתר את פסק הדין ואת ניקוד האיום. שימו לב ש"זיהוי AV גבוה" + "ניקוד איום נמוך" הוא בדיוק החתימה של EICAR: מזוהה לפי שם, אך בלתי מזיק בהתנהגות.
  3. 4.3 מצאו את מיפוי MITRE ATT&CK

    גללו אל מקטע MITRE ATT&CK™ של הדוח.

    This section maps observed behaviour to ATT&CK techniques, e.g.:
  T1059  Command and Scripting Interpreter
  T1112  Modify Registry
  T1071  Application Layer Protocol (C2)
For the harmless EICAR file this section is empty or minimal -
it is most useful when reading a real malware report.
    אתם יודעים היכן נמצא מיפוי ATT&CK וכיצד נראה מזהה טכניקה (מספר T + שם).
  4. 4.4 מצאו את ה-IOCs ואת הקבצים שנוצרו

    גללו אל המקטעים Indicators / Network ו-Extracted Files.

    Hybrid Analysis lists, in one place:
  - Hashes (MD5, SHA-1, SHA-256) of the sample
  - Contacted domains, URLs and IP addresses
  - Files dropped/created on disk during execution
  - Registry keys created or modified
You can download the full IOC set as a CSV/JSON from the report.
    אתם יכולים לאתר כל קטגוריית IOC בדוח של Hybrid Analysis. עבור EICAR רשימות אלה ריקות; עבור נוזקה אמיתית הן ההעברה שלכם להנדסת זיהוי.
אם זה לא עבד — אין תוצאה לגיבוב: ייתכן ש-Hybrid Analysis לא מאנדקס את הדגימה המדויקת הזו. חפשו את מילת המפתח eicar במקום, ופתחו דוח ציבורי עדכני כלשהו כדי להתאמן בקריאת הפריסה.

שלב 5 — השוואת שלושת ארגזי החול

לכל ארגז חול יש חוזק שונה. מלאו את התצפיות שלכם משלבים 1–4, ואז השוו מול הטבלה הזו.

ארגז חולמהירותאינטראקטיביותרמת פירוט הדוחעלות (שכבה חינמית)הכי מתאים ל-
VirusTotalמהיר מאוד (שניות)אין — אוטומטי בלבדיחס רב-AV + סיכום התנהגותחינם, אין צורך בחשבוןבדיקה מהירה ראשונה; חיפושי גיבוב
Any.runחי (אתם צופים בו רץ)גבוהה — אתם יכולים ללחוץ במכונה הווירטואליתעץ תהליכים חי + רשת + וידאוחשבון חינמי; משימות ציבוריות בלבדצפייה בהתנהגות מתפתחת; נוזקה רב-שלבית
Hybrid Analysisדקות (הפעלה מלאה)נמוכה — אוטומטיהגבוהה ביותר — מפת MITRE, IOCs מלאים, קבצים שנוצרוחשבון חינמידוח כתוב מפורט; חילוץ IOC
אתם יכולים להמליץ על הכלי הנכון: VirusTotal למיון מהיר, Any.run לצפייה בהתנהגות באופן אינטראקטיבי, Hybrid Analysis לדוח הכתוב המעמיק ביותר ולרשימת IOC. אנליסט אמיתי משתמש בכל השלושה יחד.

שלב 6 — חילוץ ותיעוד IOCs

מטרת ארגזי החול היא להפיק IOCs (סימני התפשרות) שה-SOC יכול להפוך לזיהויים וחסימות. אספו אותם מהדוחות לתוך הערה מובנית אחת.

  1. 6.1 צרו קובץ הערות IOC
    In the Administrator PowerShell window, run:
notepad C:\lab6\iocs.txt
(Click "Yes" if Notepad offers to create the file.)
    Notepad פותח קובץ iocs.txt ריק בתיקיית המעבדה.
  2. 6.2 רשמו את קטגוריות ה-IOC

    הקלידו את התבנית הזו ב-Notepad ומלאו אותה מהדוחות שקראתם. עבור קובץ הבדיקה EICAR רוב השורות יאמרו "none — harmless test file"; עבור נוזקה אמיתית כל שורה נושאת ערכים אמיתיים.

    === IOC REPORT — EICAR test file ===
Date analysed   : 2026-05-20

מתי אסור להעלות — דליפת נתונים

כל דבר שמועלה לארגז חול ציבורי עלול לצאת משליטתכם. VirusTotal, מצב ציבורי של Any.run, ו-Hybrid Analysis כולם הופכים הגשות לגלויות למשתמשים אחרים ולמנויים משלמים. לעולם אל תעלו: קבצים ארגוניים ייחודיים או פנימיים; מסמכים שעשויים להכיל נתוני לקוחות או עובדים; קבצים ששמם או תוכנם חושף את הארגון שלכם; או דגימה מתקפה ממוקדת שנוכחותה באתר ציבורי תזהיר את התוקף. כאשר עליכם לנתח קובץ כזה, העדיפו תחילה חיפוש גיבוב, ואז השתמשו במצב הגשה פרטי/בתשלום או בארגז חול מקומי (Cuckoo, CAPE) שבשליטתכם.

סיכום

ארגזי חול אוטומטיים הופכים קובץ חשוד למודיעין מעשי במהירות. VirusTotal נותן פסק דין רב-AV מיידי וסיכום התנהגות. Any.run מאפשר לכם לצפות בנוזקה רצה בזמן אמת ולתקשר איתה. Hybrid Analysis מפיק את הדוח הכתוב המעמיק ביותר עם מיפוי MITRE ATT&CK ורשימת IOC מלאה. תמיד העדיפו חיפוש גיבוב — שום דבר לא עוזב את המחשב שלכם ואין בעיית אנטי-וירוס. העלו קובץ רק כאשר הוא אינו מוכר וגם אינו רגיש, מכיוון שהגשות ציבוריות עלולות לדלוף. התוצר של כל ניתוח ארגז חול הוא דוח IOC מובנה שה-SOC משתמש בו לחסימה, ציד וזיהוי.
