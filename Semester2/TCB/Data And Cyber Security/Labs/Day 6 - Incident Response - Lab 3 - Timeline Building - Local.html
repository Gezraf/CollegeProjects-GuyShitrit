תרחיש האירוע

מזהה אירוע: INC-2026-0099 · תאריך: 2026-05-18 (יום ב')

קיבלת תיקיית ראיות (C:\IR) שנאספה ע"י אנליסט ב-Lab 2 Local ממכונה WS-SALES-07. המשימה שלך: לנתח את כל הראיות, לבנות ציר זמן מלא של ההתקפה, לזהות את כל ה-IOCs, ולמפות כל שלב ל-Cyber Kill Chain ול-MITRE ATT&CK.

לא ביצעת את Lab 2? אין לך תיקיית ראיות?
  1. אופציה A — Sample Evidence Pack: בקש מהמדריך את חבילת הראיות המוכנה (קובץ ZIP עם כל ה-CSV/TXT/EVTX). חלץ ל-C:\IR\.
  2. אופציה B — נתונים מוטמעים: כל שלב למטה כולל "פלט צפוי" עם נתוני הראיות. אתה יכול לעבוד על המעבדה רק מהפלטים המוטמעים — אין צורך בקבצים אמיתיים.
  3. אופציה C — צור בעצמך: חזור ל-Lab 2 Local והרץ את הפקודות על מכונת Windows (אפילו על המכונה שלך — אם אין malware אמיתי, התוצאות יהיו "נקיות" אך תלמד את הזרימה).

  • netstat_full.txt — חיבורי רשת

דרישות מוקדמות

  • מכונת Windows עם הרשאות Administrator
  • Event Viewer (מובנה ב-Windows)
  • גישה לקבצי הראיות ב-C:\IR (ממעבדה 2, או קבצי דוגמה)
  • דפדפן עם גישה ל-VirusTotal (virustotal.com)
  • דפדפן עם גישה ל-MITRE ATT&CK (attack.mitre.org)
  • אופציונלי: Notepad++ או VS Code לניתוח קבצי טקסט
  • מסמך Word / טבלת Excel לתיעוד ציר הזמן

  1. שלב 1
    ניתוח תהליכים (processes_wmic.csv)

    פתח את C:\IR\processes_wmic.csv ב-Excel או Notepad++.

    חפש תהליכים חשודים לפי הקריטריונים הבאים:

    • תהליכים שרצים מ-C:\Users\*\AppData\ או C:\Temp\
    • תהליכים עם שמות של תהליכי מערכת (svchost, csrss) אך מנתיב שגוי
    • PowerShell עם פרמטרים -enc (encoded) או -w hidden
    • תהליכים ללא חתימה דיגיטלית (unsigned)
    REM === סינון תהליכים חשודים ===
REM פתח CMD ב-C:\IR:
findstr /i "Temp AppData ProgramData" processes_wmic.csv > suspicious_processes.txt
findstr /i "powershell cmd" processes_wmic.csv > shell_processes.txt

    מלא את הטבלה:

סיכום

בניית ציר זמן ידנית מלמדת אותך להבין כל ראיה ומה היא אומרת. גם כשיש כלים אוטומטיים, היכולת לנתח Event Logs, קבצי process, ו-network artifacts ידנית — ולחבר אותם לסיפור מלא — היא מיומנות יסודית. מיפוי ל-Kill Chain נותן את ה"סיפור" של ההתקפה, ומיפוי ל-MITRE ATT&CK נותן את הדיוק הטכני. שניהם יחד = ציר זמן מקצועי שמספר בדיוק מה קרה, מתי, ואיך.
